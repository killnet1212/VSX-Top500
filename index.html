Как формируется рейтинг

Данные запрашиваются напрямую из публичного API Visual Studio Marketplace: топ-500 расширений по числу установок. Результат кешируется в браузере на текущие сутки, а в полночь рейтинг автоматически перестраивается — так вы видите изменения позиций день ко дню.

Подборки, два языка и бейдж «Спонсор»

В навигации над рейтингом собраны тематические подборки: ИИ и нейросети, Python, игры, веб-разработка, данные, DevOps и другие. Сайт работает на русском и английском, а расширения с кнопкой поддержки автора помечены бейджем «Спонсор» — как в VS Code.

Работа без интернета

Скачайте свежий снимок рейтинга и положите файл top500.json рядом с index.html — сайт откроется и покажет рейтинг даже без подключения к сети.

Данные: Visual Studio Marketplace. Сайт не аффилирован с Microsoft.
